Conjunto de Dados

Visão Geral
No sentido de estabelecer uma base de dados de ligação entre os indicadores de qualidade da ANEEL é disponibilizada a base de dados de municípios
contendo a chave de ligação para os demais conjuntos de dados de Indicadores de Qualidade em Energia Elétrica.

Metadados
Nome do arquivo:
Indqual-municipio (csv, xml e json)
Resumo descritivo do arquivo:
Conjunto de dados contendo a relação de municípios com a identificação do Identificador do Conjunto de Unidades Consumidoras para correlacionar
com os outros arquivos de Dados Abertos de Indicadores de Qualidade em Energia Elétrica.
Catálogo origem
https://dadosabertos.aneel.gov.br
Órgão responsável
ANEEL – Agência Nacional de Energia Elétrica
IndQual Município
